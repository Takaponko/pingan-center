📥 数据导入

当前为纯前端应用，无法真实抓取小红书内容：粘贴后仅记录链接并生成占位笔记，标题 / 作者 / 指标为模拟数据，后续可回填。
格式说明：
{ "notes": [{ "title":"笔记标题","author":"博主","spend":320000, "exposure":1280000,"commentCount":1520,"like":46000, "health":88,"risk":"low|mid|high","industry":"数码" }], "comments": [{ "noteId":"N1","author":"用户","time":"2 分钟前", "text":"评论内容","nps":"promoter|passive|detractor", "cat":"praise|high_intent|faq|negative|competitor|off_topic", "reco":"AI 研判建议" }] } notes 可不写 id，按数组顺序自动生成 N1、N2… comments 的 noteId 填笔记 id 或数组下标（从 1 开始）
表头字段：noteId, author, time, text, nps, cat, reco（顺序任意，缺字段自动补全）。nps 取值 promoter / passive / detractor；cat 取值 praise / high_intent / faq / negative / competitor / off_topic。
